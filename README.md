## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/ChainCove.git`
2. `cd ChainCove`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure ChainCove, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
